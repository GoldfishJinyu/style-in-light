# 美学坐标

一个从穿搭、物件、艺术和音乐探索个人美学的静态网站。[打开已部署的网站](https://goldfishjinyu.github.io/style-in-light/)

- 风格图鉴包含 28 种风格。可筛选来源背景、视觉特征、材质、轮廓、装饰、氛围、用途及多值时代和地区，也可搜索中英文名称与元素。时代和地区表示主要与相关灵感语境。
- 一套 9 题短测。视觉题权重最高，醒目程度和使用场景的权重较低。不想尝试的元素会降低包含该标签的风格排名。穿搭示例偏好和最后的尝试领域只影响报告呈现。
- 网页报告推荐三个风格方向，展示重合标签、共同元素和三个程度的尝试方法。反馈可以减少指定元素、调整氛围与穿搭的相对权重，或优先推荐更日常的风格。
- 提供简体中文、繁体中文、English 及浅色、深色两种界面。语言和主题保存在浏览器中，刷新页面会清空问卷答案。

双击 `dist/index.html` 本地预览。网站使用原生 HTML、CSS 和 JavaScript。推送到 `main` 会触发 GitHub Actions 将 `dist` 发布到 GitHub Pages。

## 内容和授权

- `dist/catalog.js` 包含中英文图鉴内容和分组。`dist/guide.js` 定义多维标签、比较说明和氛围参考。`dist/questions.js` 包含问卷、标签权重和反馈规则。
- `dist/images.js`、`dist/image-alts.js` 和 `dist/image-licenses.js` 记录真实素材、替代文字、源文件、作者、许可、署名要求与核对日期。页面展示经过核对的图片，待核实的素材显示占位提示。部分封面裁切，文件为网页缩放或压缩。
- `dist/fonts/` 包含本地托管的 DM Sans、DM Serif Display、Noto Serif SC 和 Noto Serif TC 以及对应的 SIL 开放字体许可证。中文标题字体包含网站文案所用字符的子集，其他字符使用系统字体。
