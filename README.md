# 美学坐标

一个中文个人风格探索网站。双击 `dist/index.html` 即可预览，也可以用 VS Code 打开整个项目目录。

- `dist/index.html` 是页面结构。
- `dist/style.css` 控制排版、配色和响应式布局。
- `dist/app.js` 包含风格图鉴、问卷、评分和报告。
- `dist/*.jpg` 是用内置 ImageGen 生成并裁切的图片。首页是橙色马蹄莲、钴蓝花器与红椅。图鉴分别展示浅色陶杯、暖色粗陶、撞色家具和冷调金属家具。

用户可以跳过昵称与年龄段。前七题推荐主风格，有相关线索时也会给出备选风格。颜色、材质、物件和空间偏好在评分中权重较高。最后一题决定报告优先显示哪类灵感。年龄段只显示在当次报告中。

答题内容和报告保存在当前页面的内存里。刷新页面会清空。项目使用原生 HTML、CSS 和 JavaScript，可以直接把 `dist` 目录发布到静态托管服务。
